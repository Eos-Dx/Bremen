PR0139 — Aramina model-specific failure matrix and repair
Research draft / technical verification only; requires radiologist review.

BEFORE: 0.2.12-beta
Exact stage: _run_local_artifact -> LR1 Pipeline.predict_proba ->
StandardScaler.transform -> feature-count validation.
Exception: ValueError. Received unnamed numpy array (1, 2000); fitted scaler
and LR1 estimator both require 100 features. Artifact loading/validation passed.
Category B (pipeline input mismatch), with category A (profile width mismatch).
The artifact owns raw-detector preprocessing, integration.npt=100, and XRD
v0.1.7-beta. The previous path bypassed that preprocessing. Resizing or slicing
canonical profiles would not implement this contract and was not used.

BEFORE: 0.2.13-beta
Exact stage: joblib deserialization before _validate_artifact.
Exception: ModuleNotFoundError for aramina.target_breast_model.
Exact observed missing symbol: aramina.target_breast_model.GatedSymmetryLogistic.
The original bridge supplied only aramina.m2q_model.GatedSymmetryLogistic.
No missing structural key or kind/type mismatch caused this original failure:
after installing the exact Bremen-owned compatibility class, the actual artifact
loads and validates. kind=aramina_training_artifact; artifact version=0.3;
model_identity=[aramina_target_breast_risk, 0.2.13-beta]; one selected model.
The actual fitted LR1 is StandardScaler -> LogisticRegression, both with 100
features. It is NOT the 256-bin FPCA design present in newer producer source.
The embedded prediction preprocessing specifies XRD v0.1.9-beta and npt=100.

REPAIR
Both models execute their own full artifact-declared raw H5 preprocessing.
Dedicated local XRD workers isolate v0.1.7-beta and v0.1.9-beta from Bremen's
unchanged v0.1.5-beta dependency. A shared upgrade was tested and rejected
because it removed SelectColumnsTransformer, which Bremen imports.
No external Aramina package, external Aramina import, provider URL, or HTTP
provider is introduced. Only local preprocessing uses a subprocess; fitted
estimators stay in the main process. No model weights or thresholds change.

The final feature contract is preserved: sigmoid of mean clipped LR1 logits,
measured age/availability, and the producer's versioned Core4 paired symmetry
calculations. This replaces the old proxy statistics. Missing-pair symmetry is
handled by the model's trained gate, not by a probability fallback. Unknown
final columns or missing thresholds fail instead of receiving invented defaults.
The 0.2.13 compatibility class preserves its fitted numeric coercion, imputation,
scaling and gating behavior; the legacy 0.2.12 compatibility class is unchanged.

AFTER: local FastAPI POST /demo/api/jobs equivalent
Real local model artifacts and raw H5 files; explicit model IDs; only source
resolution mapped to the local files. Normalization, catalog provider selection,
preprocessing, LR1, final-model inference, and report construction are real.
No inference or probability mocks were used. Successful workflow/report model
versions were asserted non-empty and equal to the selected artifact version.
Public responses/events were checked for diagnostic leakage.
Production input byte identity, deployed dependencies, and a production rollout
were not verified. Other production matrix patients were not rerun locally.
