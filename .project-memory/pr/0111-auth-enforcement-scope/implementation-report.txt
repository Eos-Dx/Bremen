## AUTH_DISABLED_BEHAVIOR_PRESERVED
Yes — When auth is disabled (default), _check_auth_gate returns None for all requests. All protected routes behave exactly as before with no token required.

Yes — When auth is enabled, the following routes require valid Bearer access token:

- GET /demo/workspace
- GET /demo/workspace/{job_id}

## PUBLIC_ROUTES_REMAIN_PUBLIC
Yes — Public pages never require auth even when enabled:
- GET /demo, /demo/login, /demo/control-room, /demo/api-docs
- GET /demo/model-guide, /demo/model-playground
- GET /model/version, /health, /demo/api/models

## TOKEN_REFRESH_ROUTES_REMAIN_PUBLIC
Yes — POST /demo/api/auth/token and POST /demo/api/auth/refresh are never gated.

## SAFE_401_SHAPE_VERIFIED
Yes — 401 responses contain only: {"error": "Authentication failed", "token_type": "Bearer", "technical_demo_only": true}. No password hashes, signing secrets, config values, stack traces, or internal paths exposed.

## NO_SECRET_EXPOSURE
Yes — Auth gate only reads config, validates token, and returns generic error. No secrets, hashes, or internals leak in any response path.
