## Production Bug Summary
Valid Aramina POST /demo/api/jobs reached runtime but failed with
ARAMINA_UNSUPPORTED_ARTIFACT. Root causes:
1. Real Aramina joblib contains pickle class `aramina.m2q_model.GatedSymmetryLogistic`
   which pickle cannot resolve without a Bremen-owned compatibility bridge.
2. PR0136 implemented fake 7-stat feature extraction instead of real Aramina scoring.

## Exact Root Cause Fixed
1. Compatibility bridge: `aramina_artifact_compat.py` registers a real
   `GatedSymmetryLogistic` class in `sys.modules["aramina.m2q_model"]`
   that preserves exact prediction behavior using the unpickled fitted
   attributes (base_scaler_, symmetry_means_, symmetry_scales_, logreg_).
2. Fake 7-stat features removed. lr1_model now receives a profile_matrix
   of raw intensity arrays. final_model receives a pandas DataFrame with
   named feature columns from model_info["feature_columns"].
