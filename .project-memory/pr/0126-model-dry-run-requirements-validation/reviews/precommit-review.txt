PR GOAL
-------
POST /demo/api/models/{model_id}/requirements/validate behaves like a
read-only dry run of the real model pipeline when valid
container_requirements.json exists. Previously it only checked request
payload fields. Now it resolves the real source, normalizes H5, resolves
the workflow provider, and executes the full pipeline in read-only mode.

This catches input_preparation failures (e.g. Nova_103_.h5) that
request-payload-only validation missed.
