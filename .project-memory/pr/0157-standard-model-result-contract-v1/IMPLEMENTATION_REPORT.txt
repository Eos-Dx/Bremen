SUMMARY
Implemented Standard Model Result Contract v1 (docs/standard_model_result_contract_v1.md,
ADR-0018) for both Bremen and Aramina BEHIND the existing API surface. Introduced one
authoritative platform mapping boundary that consumes already-produced model runtime
results (never recomputes science) and emits the canonical result envelope, attached
additively to the existing report at the single get_job_report boundary. HTTP routes,
methods, auth, request semantics, job/event/report semantics, model_id/workflow_id, and
legacy report payload fields are unchanged and frozen-verified. No model science changed.

ARCHITECTURE (as implemented)
  Model package runtime result (native, authoritative)  +  platform/source metadata
      -> bremen.api.model_result_mapper (build_standard_result; workflow_id dispatch)
      -> bremen.api.standard_model_result.StandardModelResult (canonical v1 envelope)
      -> ReportEnvelope.standard_result (OPTIONAL, additive)
      -> get_job_report -> existing FastAPI + legacy http.server report routes -> consumers
Mapper is platform/integration only; model packages know nothing about it. Dependency
direction preserved: api -> package manifest (platform -> package), never the reverse.

MODEL METRICS SOURCE
No authoritative sensitivity/specificity exists in any package manifest, artifact
metadata, or runtime result for the current releases. The PR0155 example values in
the contract doc (0.96053 / 0.49495 / 0.41303) exist nowhere in the repo (verified);
ADR-0008 defines target_sensitivity as a TRAINING/THRESHOLD-CALIBRATION target, not
achieved clinical validation, and forbids reporting it as validated. Therefore the
mapper reports model_metrics = {sensitivity: null, specificity: null} (explicit
absence). A future release that provides provenance-verified metrics should thread
them through _empty_metrics/manifest; the mapper never hardcodes them.

MODEL_METHOD RULE
Implemented ONCE: mapper._model_method(model_version) -> returns model_version.
Documented + tested. No per-provider constant duplication.

TIMESTAMP RULE
Shared mapper.normalize_timestamp(value): parse ISO/RFC3339; strip microsecond to 0
(remove fractional seconds); emit datetime.isoformat() preserving any offset the
source carried. Preserves the source instant; does NOT coerce naive values to local
time or invent a zone (naive input -> naive output). created_at derives from tz-aware
generated_at so it is always tz-aware; absent scan_date_time -> "".
Tests: tz-aware, fractional strip (Z + +02:00), already-normalized idempotent,
naive-preserved, empty/unparseable -> "".
