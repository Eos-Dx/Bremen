# PR0133 Precommit Review — Aramina Provider Adapter Contract Alignment

Branch: 0133-aramina-provider-adapter-contract-alignment
PR Goal: Align Bremen's Aramina provider adapter with the official Eos-Dx/Aramina runtime contract.

## Official Aramina Contract Checked

- Aramina runtime is a separate FastAPI service
- Uses ARAMINA_MODEL_PATH for model.joblib
- /health returns ready when model artifact exists
- /predict accepts multipart input_h5 + request_json
- request_json: analysis_author, prediction_comment, patient_id, target_side
- target_side normalizes to left/right
- Returns external_report / internal_report

## Production Evidence Addressed

Before PR0133, Bremen had no actual Aramina /predict contract — `_call_aramina_provider` was a stub returning empty results. Now Bremen builds the official request_json with only the 4 allowed fields, validates patient_id and target_side before the provider call, and normalizes the provider response (external_report only, internal_report stripped).
