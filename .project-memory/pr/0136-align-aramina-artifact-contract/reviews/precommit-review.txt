execution path but failed with ARAMINA_UNSUPPORTED_ARTIFACT. The old
workflow_aramina.py expected an invented flat artifact structure

- All PR0136 code changes are guarded by artifact_type == "aramina.joblib.model_package" or workflow_id == "aramina".
- No dependency merging. No contract weakening.

## Real Aramina Artifact Contract (implemented)
  _validate_artifact checks:
    1. package is dict
    2. kind == "aramina_training_artifact"
    3. models is dict with exactly one model
    4. model_identity has name and version
    5. prediction_preprocessing_yaml is non-empty string
    6. prediction_contract_yaml is non-empty string
    7. model_info has lr1_model, final_model, thresholds, feature_columns, class_definition
    8. lr1_model and final_model support predict_proba
    9. model_identity.version matches entry.model_version (mismatch → ARAMINA_MODEL_IDENTITY_MISMATCH)

## Old Wrong Bremen Aramina-Runner Expectation (removed)
  Previously required: top-level model, positive_class, feature_contract with
  schema_version="aramina.canonical_intensity.v1", position, q_grid, normalization.
  These assumptions no longer block the real production Aramina artifact.

## Adapter Implemented
  _validate_artifact: validates real production artifact structure
  _select_measurements: selects target-side measurements from canonical H5
  _compute_measurement_features: per-measurement statistical features
  _build_lr1_features: feature array for lr1_model from single measurement
  _prepare_features: builds target_features, control_measurements from H5
  _run_local_artifact: full scoring pipeline (lr1 → logit aggregate → final_model → threshold)
