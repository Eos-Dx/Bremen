New contract (PR0136):
  kind == "aramina_training_artifact"

  model_info.final_model (predict_proba)

Scoring sequence:
  1. Load H5, extract measurements for patient
  2. Select target-side measurements
  3. Build per-measurement feature rows
  4. Score with lr1_model
  5. Aggregate LR1 logit averages
  6. Compute symmetry features if available
  7. Run final_model.predict_proba on aggregated features
  8. Apply threshold_target from thresholds
  9. Build safe external_report output

Feature columns for final_model:
  profile_p_cancer_logit_average, age, age_available,
  sk_wasserstein_distance_full_q2, sk_weightedrms1, sk_weightedrms2,
  sk_mean_peak_value_abs_delta, symmetry_available

Key constraint:
  lr1_model and final_model are sklearn models serialized via joblib.
  They work with existing sklearn dependency — no Aramina package needed.

Safe output fields:
  model_name, model_version, target_side, risk_probability,
  target_class_risk_level, decision_threshold, reliability, reliability_reason
