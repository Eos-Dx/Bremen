PR0104J — FastAPI default runtime cutover
==========================================

Branch: 0104j-fastapi-default-runtime-cutover
PR Target: dev
Purpose: Switch default runtime for python -m bremen serve from legacy http.server to FastAPI/ASGI.

SUMMARY
-------
Changed DEFAULT_BACKEND from "http" to "fastapi" in __main__.py.
python -m bremen serve now selects FastAPI by default. Legacy http.server
remains available via --backend http or BREMEN_SERVER_BACKEND=http.

DEFAULT_RUNTIME_CHANGE
----------------------
DEFAULT_BACKEND = "fastapi" (was "http").
resolve_backend(None, None) now returns "fastapi".

After this PR:
- python -m bremen serve                     -> FastAPI (default)
- python -m bremen serve --backend fastapi   -> FastAPI
- python -m bremen serve --backend http      -> legacy http.server
- BREMEN_SERVER_BACKEND=fastapi python -m bremen serve -> FastAPI
- BREMEN_SERVER_BACKEND=http python -m bremen serve    -> legacy http.server
- CLI --backend still wins over BREMEN_SERVER_BACKEND

RUNTIME_BACKEND_RESOLVER
------------------------
resolve_backend(cli_backend, env_backend) -> str:
  - CLI wins when not None/empty
  - Valid env used when CLI absent
  - Default: "fastapi"
  - Invalid raises ValueError (safe message)

ENV_BACKEND_BEHAVIOR
--------------------
BREMEN_SERVER_BACKEND env var read via os.environ.get().
Valid values: http, fastapi (case-insensitive, whitespace-trimmed).
Invalid values fail closed.

CLI_OVERRIDE_BEHAVIOR
---------------------
--backend flag overrides BREMEN_SERVER_BACKEND. Default for --backend
on the parser is None so resolver distinguishes explicit CLI from absence.

INVALID_ENV_BEHAVIOR
--------------------
- Non-zero exit code (1)
- Safe generic error message
- No server launched
- No raw env value exposed
- No traceback

LEGACY_FALLBACK_BEHAVIOR
------------------------
Legacy http.server available via:
- python -m bremen serve --backend http
- BREMEN_SERVER_BACKEND=http python -m bremen serve
src/bremen/api/server.py preserved. Legacy handler import preserved.

SERVE_FASTAPI_PRESERVED
------------------------
serve-fastapi remains a separate command. Unchanged.

FASTAPI_FACTORY_TARGET_PRESERVED
--------------------------------
FastAPI path uses bremen.api.fastapi_app:create_fastapi_app with uvicorn.

DOCKER/ENTRYPOINT/CMD DECISION
-------------------------------
Dockerfile NOT changed.
Dockerfile runs: ENTRYPOINT ["python", "-m", "bremen"] CMD ["serve", "--host", "0.0.0.0", "--port", "8080"]
With DEFAULT_BACKEND = "fastapi", this automatically selects FastAPI.
No Dockerfile change needed — the code-level default handles the cutover.
Production runtime after PR: FastAPI/ASGI via uvicorn (through code default).
