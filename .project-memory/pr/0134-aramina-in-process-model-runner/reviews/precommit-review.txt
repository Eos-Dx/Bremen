## VERDICT: READY FOR COMMIT

## Main PR Goal
Make the existing inference system execute BOTH Bremen and Aramina ML models from the same App Runner service via a single `POST /demo/api/jobs` endpoint, selected by `model_id`. Aramina becomes a catalog model artifact — not a package, not a service, not a dependency, not an external HTTP provider.

## Architecture Confirmed
- ONE service, ONE endpoint (`POST /demo/api/jobs`), model selection by `model_id`.
- Bremen model: existing BremenProvider, unchanged.
- Aramina model: `AraminaWorkflowProvider` executes in-process using staged artifact + local sklearn estimator.
- No HTTP provider. No external service. No Aramina package dependency.
- Aramina artifact staged during S3 discovery, deserialized on execution path via `_load_staged_artifact`.
