PR0104H — FastAPI runtime selection gate
========================================

Branch: 0104h-fastapi-runtime-selection-gate
PR Target: dev
Purpose: Add explicit --backend flag to the serve command for runtime selection.

SUMMARY
-------
Added --backend argument to the serve subcommand in __main__.py.
Default remains legacy http.server. The serve-fastapi command is unchanged.

RUNTIME_SELECTION_BEHAVIOR
--------------------------
- python -m bremen serve                     -> legacy http.server (default)
- python -m bremen serve --backend http      -> legacy http.server
- python -m bremen serve --backend fastapi   -> FastAPI/ASGI via uvicorn
- python -m bremen serve-fastapi             -> FastAPI/ASGI via uvicorn (unchanged)

DEFAULT_BACKEND_PRESERVED
-------------------------
Default is http (legacy http.server). No production cutover.

SERVE_FASTAPI_PRESERVED
------------------------
serve-fastapi remains a separate command. Does not accept --backend.

FASTAPI_FACTORY_TARGET_PRESERVED
--------------------------------
FastAPI serving uses bremen.api.fastapi_app:create_fastapi_app with uvicorn factory mode.

FILES CHANGED
-------------
src/bremen/__main__.py (modified)
  - Added --backend argument to _add_serve_subcommand with choices [http, fastapi], default http
  - Updated _handle_serve to dispatch based on args.backend
  - backend=fastapi calls run_fastapi_server from api.fastapi_server
  - backend=http calls run_server from api.server (unchanged legacy path)
  - Graceful fallback: if backend attr missing, defaults to http

tests/test_bremen_fastapi_serve_mode.py (modified)
  - Added TestCLIServeBackendSelection (5 tests): parser tests for --backend flag
  - Added TestServeFastapiPreserved (2 tests): serve-fastapi unchanged, no --backend
  - Added TestServeDispatch (3 tests): monkeypatched dispatch tests for http/fastapi/default

ZERO_SERVER_POLICY_PRESERVED
-----------------------------
All new tests use parser assertions and monkeypatched dispatch. No real servers, no sockets, no localhost HTTP.
