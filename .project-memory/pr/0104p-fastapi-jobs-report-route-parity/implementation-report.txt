PR0104P — FastAPI jobs/report read route parity hotfix
======================================================

Branch: 0104p-fastapi-jobs-report-route-parity
PR Target: main
Purpose: Add FastAPI parity for legacy job/report read routes used by Control Room.

PROBLEM
-------
FastAPI runtime could create jobs and stream events, but:
- GET /demo/api/jobs -> 405 (no route)
- GET /demo/api/jobs/{job_id} -> 404 (no route)
- Report routes missing entirely

SOLUTION
--------
Added four FastAPI routes reusing legacy business logic:
- GET /demo/api/jobs -> list_analysis_jobs()
- GET /demo/api/jobs/{job_id} -> job detail with execution traces
- GET /demo/api/jobs/{job_id}/reports -> get_job_reports()
- GET /demo/api/jobs/{job_id}/reports/{workflow_id} -> get_job_report()
