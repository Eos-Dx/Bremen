# PR0130 Precommit Review — Hotfix Aramina Manifest Validation

Branch: 0130-hotfix-aramina-manifest-validation
PR Goal: Hotfix Aramina manifest validation so valid Aramina manifests are not rejected by the Bremen-only manifest validator.

## Production Evidence Addressed

After uploading two Aramina model packages to S3, app startup completed but catalog showed `candidate_count=5, available_count=3, rejected_count=2` with `reason_category=manifest_validation_failed`. Root cause: `discover_models` called `validate_model_manifest(data)` (Bremen-only) before branching on `artifact_type`, rejecting Aramina manifests for missing Bremen-specific fields. Fix: read `artifact_type` early and skip the Bremen-only validator for Aramina manifests.

## Files Changed

- `src/bremen/api/s3_model_discovery.py` (+28/-6) — Branch validation by artifact_type before calling Bremen-only validator; add Aramina-specific checksum and filename validation
- `tests/test_s3_model_discovery.py` (+295) — 9 new Aramina manifest validation tests
- `tests/test_aramina_workflow_runtime.py` (+4/-4) — Update test checksums to valid 64-char hex
