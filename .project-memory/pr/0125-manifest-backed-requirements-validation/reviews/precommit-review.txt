SUMMARY
-------
PR0125 makes POST /demo/api/models/{model_id}/requirements/validate
perform safe manifest-backed pre-submit request validation when valid
container_requirements.json exists. Validation is request-payload-only:
it checks that required request fields are present. It must not open H5,
call S3, run inference, create jobs, or create reports.

When no valid container_requirements exist, the existing PR0122 no-op
behavior is preserved unchanged.
