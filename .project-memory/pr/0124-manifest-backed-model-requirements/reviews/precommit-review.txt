SUMMARY
-------
PR0124 reads optional container_requirements.json next to the model
package during S3 model discovery, stores valid requirements privately
on RegistryModelEntry, and makes GET /requirements return
requirements_available=true only when valid requirements exist.
POST /requirements/validate remains a no-op.
Invalid requirements are silently ignored — the model remains available.
