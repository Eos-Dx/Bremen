SHARED-SERVER ISOLATION MECHANISM

--- Analysis ---

The server_info fixture creates a handler class that captures two pieces of
mutable state in its closure:

1. _job_store: an InMemoryJobStore instance
2. _version: a static version string (immutable)

The handler methods access these at CALL time (not creation time), which means
clearing _job_store._jobs between tests gives each test a fresh job store.

ModelState is accessed lazily via ModelState.is_ready(), ModelState.get_model(),
ModelState.get_instance(). These call the singleton pattern stored on the bremen
package. Calling ModelState.reset_for_tests() clears it.

The registry is accessed lazily via get_registry() which reads from the bremen
package attribute. Calling model_registry.reset_for_tests() clears it, and
initialize_registry() sets it.

--- Verdict: Shared server IS feasible with per-test reset ---

Evidence from source code:

In server.py _make_handler:
- _prepare_job_store is referenced at call time in do_POST for /predictions
- ModelState.is_ready() is called at route-handling time
- get_registry() is called at route-handling time

All mutable state is read lazily. If we reset these between tests, the same
handler and server can serve multiple test invocations with clean state.

--- Required per-test reset pattern ---

For a session-scoped server_info, each test must call:

    from bremen.api.model_state import ModelState
    from bremen.api.jobs import InMemoryJobStore
    from bremen.api.model_registry import reset_for_tests as reset_registry, initialize_registry, build_legacy_registry

    ModelState.reset_for_tests()
    reset_registry()
    session_job_store._jobs.clear()       # clear shared job store
    ModelState.reset_for_tests()           # clear singleton
    # Re-init registry with clean state
    handler = _make_handler(session_job_store, version="test-version", load_model=True)
    # But handler is already captured in the server... we can't change it.
    # So we need to clear the job_store, not replace it.

PROBLEM: _make_handler with load_model=True calls _load_synthetic_model()
which calls ModelState.load_at_startup(). If we clear ModelState between tests,
the next test that needs the model must re-load it. But ModelState.load_at_startup()
is called once during _make_handler() — not per-request.

This means:
1. If test A uses a route that reads ModelState (like /demo starts page),
   ModelState must be loaded.
2. If test B resets ModelState, model state is gone.
3. If test C needs ModelState again, it won't have it because the handler
   only loaded it at creation time.

CONCLUSION: A pure shared-server approach where ModelState is reset between
tests would BREAK tests that need model info AFTER the reset.

However, for tests that DON'T read ModelState state (like TestHealth,
TestDemoRoutes — they build HTML from model_info which reads ModelState), the
model info would be missing.

WORKAROUND: Instead of resetting ModelState between tests, re-initialize it:
    ModelState.reset_for_tests()
    ModelState.load_at_startup(...)  # re-load the synthetic model

But load_at_startup triggers joblib loading costs (~5-10ms per test), and we
can't re-load without re-creating the handler...

BETTER APPROACH: Keep function-scoped fixture but eliminate thread.join cost.
Rather than sharing the server, REDUCE the cost of each fixture invocation.

--- Alternative: Shared server with scoped reset ---

If we use a session-scoped server AND an autouse function-scoped fixture that:

1. Clears job_store._jobs
2. Re-initializes ModelState with synthetic model
3. Re-initializes registry

Then tests that don't need model state skip step 2-3 via a marker.

But this adds complexity and risk of test pollution.

--- FINAL VERDICT on shared server ---

RECOMMENDATION: Do NOT implement a shared server for this PR. The isolation
mechanisms (ModelState reset, registry reset, job store clear) are technically
feasible, but the safety invariants (especially model state loading) make it
risky without deeper handler refactoring.

INSTEAD, use the fake-socket/direct-call pattern for the majority of tests,
which eliminates the socket/thread cost entirely, and keep the existing
server_info for the few tests that genuinely need HTTP round-trip.

FAKE-SOCKET OR DIRECT-CALL PATTERN

--- Pattern for direct handler invocation ---

The _make_handler() factory in server.py returns a BaseHTTPRequestHandler
subclass. We can invoke its do_GET/do_POST methods directly by populating
the handler's instance attributes.

Key handler attributes we need to set:
- self.path: str (request path including query string)
- self.headers: http.client.HTTPMessage or compatible dict-like
- self.rfile: io.BytesIO (readable binary stream for request body)
- self.wfile: io.BytesIO (writable binary stream to capture response)
- self.command: str (method name, e.g., "GET", "POST")
- self.client_address: tuple (address for logging, can be fake)
- self.server: object (can be None, but some handlers access server attributes)

Response is written to self.wfile via send_response(), send_header(), end_headers(),
and wfile.write(). We read the response from the BytesIO buffer after the call.

--- Helper function: _invoke_handler ---

Define in tests/test_bremen_api_server.py:

def _invoke_handler(
    method: str,
    path: str,
    body: bytes = b"",
    headers: dict | None = None,
    version: str = "test-version",
    load_model: bool = True,
) -> tuple[int, dict[str, str], bytes]:
    """Invoke a Bremen handler directly without real sockets.

    Creates a fresh handler instance, populates its request attributes,
    calls do_GET/do_POST, and parses the raw HTTP response from wfile.

    Parameters
    ----------
    method : HTTP method ("GET" or "POST").
    path : Request path (with optional query string).
    body : Request body bytes (for POST).
    headers : dict of request headers.
    version : Server version string passed to _make_handler.
    load_model : Whether to load the synthetic model.

    Returns
    -------
    (status_code, response_headers_dict, response_body_bytes)
    """
    from io import BytesIO
    from http.server import BaseHTTPRequestHandler
    from email.message import Message
    from bremen.api.jobs import InMemoryJobStore
    from bremen.api.server import _make_handler
    from bremen.api.model_state import ModelState
    from bremen.api.model_registry import (
        reset_for_tests as reset_registry,
        initialize_registry,
        build_legacy_registry,
    )

    # Reset singleton state for clean test isolation
    ModelState.reset_for_tests()
    reset_registry()

    job_store = InMemoryJobStore()
    handler_cls = _make_handler(job_store, version=version, load_model=load_model)

    # Re-initialize registry after ModelState is loaded by _make_handler
    legacy_registry = build_legacy_registry()
    initialize_registry(legacy_registry)

    # Prepare fake I/O streams
    rfile = BytesIO(body)
    wfile = BytesIO()

    # Create handler instance.
    # BaseHTTPRequestHandler.__init__ calls self.setup() which opens the
    # connection's makefile.  To avoid real socket I/O we override setup().
    class _FakeSocket:
        """Minimal socket-like object that returns prepared in/out streams."""

        def makefile(self, mode: str, buffering: int = -1):
            if "r" in mode or "b" in mode:
                return rfile
            return wfile

        def close(self):
            pass

    fake_sock = _FakeSocket()
    handler = handler_cls(fake_sock, ("127.0.0.1", 0), None)

    # Override auto-detected fields with our test values
    handler.command = method
    handler.path = path
    handler.request_version = "HTTP/1.0"
    handler.rfile = rfile
    handler.wfile = wfile

    # Populate request headers.
    # BaseHTTPRequestHandler.headers is an email.message.Message instance
    # built from the request line.  We rebuild it from our test headers.
    raw_header_lines = []
    if headers:
        for k, v in headers.items():
            raw_header_lines.append(f"{k}: {v}")
    raw_header_text = "\r\n".join(raw_header_lines)
    if raw_header_text:
        handler.headers = Message()
        # Manually populate header keys/values
        for k, v in (headers or {}).items():
            handler.headers[k] = v

    # Ensure Content-Length for POST (if body present and no explicit header)
    if method == "POST" and body and "Content-Length" not in (headers or {}):
        handler.headers["Content-Length"] = str(len(body))

    # Invoke the route method
    if method == "GET":
        handler.do_GET()
    elif method == "POST":
        handler.do_POST()
    else:
        raise ValueError(f"Unsupported method: {method}")

    # Parse raw HTTP response from wfile.
    # send_response + end_headers + wfile.write produce:
    #   "HTTP/1.0 200 OK\r\nHeader: value\r\n\r\nbody"
    wfile.seek(0)
    raw_response = wfile.read()

    header_end = raw_response.find(b"\r\n\r\n")
    if header_end == -1:
        # No valid HTTP response parsed
        return (0, {}, raw_response)

    # Parse status line: "HTTP/1.0 200 OK" or "HTTP/1.0 200 "
    first_crlf = raw_response.find(b"\r\n")
    status_line = raw_response[:first_crlf].decode("utf-8", errors="replace")
    parts = status_line.split(" ", 2)
    status_code = int(parts[1]) if len(parts) >= 2 else 0

    # Parse response headers
    header_section = raw_response[first_crlf + 2 : header_end]
    resp_headers: dict[str, str] = {}
    for line in header_section.decode("utf-8", errors="replace").split("\r\n"):
        if ":" in line:
            k, v = line.split(":", 1)
            resp_headers[k.strip()] = v.strip()

    body_bytes = raw_response[header_end + 4 :]

    return (status_code, resp_headers, body_bytes)

--- Alternative simpler approach ---

An even simpler pattern: define a thin wrapper that creates a handler, patched
rfile/wfile, calls the method, and returns parsed response.

def _direct_get(path: str, headers: dict | None = None) -> tuple[int, dict, bytes]:
    """Direct GET without real socket."""
    return _invoke_handler("GET", path, headers=headers or {})

def _direct_post(path: str, body: dict, headers: dict | None = None) -> tuple[int, dict, bytes]:
    """Direct POST without real socket."""
    body_bytes = json.dumps(body).encode("utf-8") if isinstance(body, dict) else body
    hdrs = headers or {}
    hdrs.setdefault("Content-Type", "application/json")
    return _invoke_handler("POST", path, body=body_bytes, headers=hdrs)
