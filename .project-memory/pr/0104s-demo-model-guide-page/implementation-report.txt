Sanitization
The provided standalone HTML was reviewed and found to include private
artifact-specific material, including a full cryptographic fingerprint,
learned numerical parameters, serialized artifact references, and raw model
internals. Those details are not served.

The integrated guide keeps only public conceptual content:
- technical demo only
- training and prediction flow at a high level
- synthetic illustration framing
- logistic regression as a transparent baseline
- clinician review remains required
- no autonomous diagnosis or clinical validation claim
