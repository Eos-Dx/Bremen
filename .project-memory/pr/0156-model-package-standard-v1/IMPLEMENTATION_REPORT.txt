SUMMARY
Defined one framework-independent Model Package Standard v1 (ownership boundary
around the existing Model Runtime Contract v1) and migrated Aramina's complete
model-specific scientific inference out of the platform/API namespace into a
dedicated model package under the PR0154 model_packages namespace. Bremen
(PR0154 package) is treated as the reference implementation and is unchanged
scientifically. Both packages now conform to the same semantic standard. HTTP
surface, model_id/workflow_id semantics, failure codes, reports, jobs, auth are
all frozen and verified unchanged. No MLflow, no registry, no science change.

STANDARD INTRODUCED
Structural (not inheritance-based) standard; NO ModelPackageBase class — the
runtime protocol already is the interface. Each conforming package owns one
authoritative source for: identity, requirements, validation, a ModelRuntime
entry point, artifact interpretation, complete inference, threshold/
postprocessing, safe diagnostics, provenance, golden tests, and a standalone-
packaging import boundary. Documented in docs/model_package_standard_v1.md and
formalized as docs/adr/0017-model-package-standard-v1.md (ADR-0017 — next free
number verified; only 0001-0016 existed). Distinguishes three layers:
ModelRuntime (callable semantics) vs Model Package Standard (deployable
ownership) vs packaging technology (future MLflow wrap).
