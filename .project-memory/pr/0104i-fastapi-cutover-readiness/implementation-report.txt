PR0104I — FastAPI production cutover readiness
===============================================

Branch: 0104i-fastapi-cutover-readiness
PR Target: dev
Purpose: Prepare for production FastAPI cutover with explicit runtime backend resolver.

SUMMARY
-------
Added deterministic resolve_backend() function that resolves server backend from
CLI --backend flag and BREMEN_SERVER_BACKEND environment variable. CLI wins over
env, env wins over default (http). Invalid values fail closed with safe error.
Default remains http for this PR — no silent flip to FastAPI.

RUNTIME_BACKEND_RESOLVER
------------------------
resolve_backend(cli_backend, env_backend) -> str:
  - CLI wins when not None/empty
  - Valid env used when CLI absent
  - Default: "http"
  - Invalid values raise ValueError (safe, no raw env leak)

Defined in src/bremen/__main__.py alongside build_parser().

ENV_BACKEND_BEHAVIOR
--------------------
BREMEN_SERVER_BACKEND env var is read by _handle_serve via os.environ.get().
Valid values: "http", "fastapi" (case-insensitive, whitespace-trimmed).
Invalid values fail closed: non-zero exit, safe error message, no server start.

CLI_OVERRIDE_BEHAVIOR
---------------------
--backend flag on serve command overrides BREMEN_SERVER_BACKEND env var.
Default for --backend is None (not "http") so resolver can distinguish
explicit CLI from absence.

Invalid env behavior
--------------------
When BREMEN_SERVER_BACKEND is invalid:
- resolve_backend raises ValueError
- _handle_serve catches it, prints safe error, returns 1
- No server launched
- No raw env value exposed in error
- No traceback

DEFAULT_BACKEND_BEHAVIOR
------------------------
- python -m bremen serve                       -> http (default)
- BREMEN_SERVER_BACKEND=fastapi python -m bremen serve -> fastapi
- python -m bremen serve --backend fastapi     -> fastapi (overrides env)
- python -m bremen serve --backend http        -> http (overrides env)

SERVE_FASTAPI_PRESERVED
------------------------
serve-fastapi remains a separate command. Unchanged.

PRODUCTION_CUTOVER_STATUS
--------------------------
This is a cutover readiness gate, not final removal. Legacy http.server
retained as explicit fallback. Dockerfile/ENTRYPOINT/CMD unchanged.

FASTAPI_FACTORY_TARGET_PRESERVED
