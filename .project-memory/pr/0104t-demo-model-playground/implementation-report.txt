PR0104T — Add demo Model Playground page
========================================

Branch: 0104t-demo-model-playground
PR Target: main
Purpose: Add a separate public sandbox/playground page to the demo.

SUMMARY
-------
Added a self-contained Model Playground page based on the uploaded
bremen_ML_demo_en.html. The page is sanitized to remove production
coefficients, SHA256, intercept, threshold, and raw model internals.
It uses synthetic placeholder values and clear sandbox/synthetic branding.
