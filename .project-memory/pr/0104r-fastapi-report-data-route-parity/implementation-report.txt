PR0104R — FastAPI report data route parity hotfix
=================================================

Branch: 0104r-fastapi-report-data-route-parity
PR Target: main
Purpose: Add FastAPI parity for external/internal report data routes.

PROBLEM
-------
GET /demo/api/reports/{job_id}/external -> 404
GET /demo/api/reports/{job_id}/internal -> 404
Report HTML opens but has no data.

SOLUTION
--------
Added two FastAPI routes reusing legacy business logic:
- GET /demo/api/reports/{job_id}/external -> build_external_report_json
- GET /demo/api/reports/{job_id}/internal -> build_internal_report_json

Both mirror handle_external_report/handle_internal_report from job_api_handler.
Error responses include technical_demo_only for safety consistency.
