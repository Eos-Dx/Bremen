PR0104G — Remove test-only local server usage from normal pytest
================================================================

Branch: 0104g-remove-server-spawning-tests
PR Target: dev
Purpose: Remove all server-spawning pytest behavior from the normal test suite.

ROOT CAUSE
----------
The normal pytest suite started real HTTPServer instances on daemon threads
and made real HTTP requests via urllib.request.urlopen, causing
ConnectionResetError noise, port conflicts, slow execution, and suite
instability.
